# Industrial Machine Failure Risk Prediction

An end-to-end machine learning system for predicting
industrial machine failure risk and supporting predictive
maintenance decisions.

## ML Techniques

- Bayes Rule
- Logistic Regression
- PCA
- Hidden Markov Models
- Random Forest
- Feature Engineering
- Model Evaluation
